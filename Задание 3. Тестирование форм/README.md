# Задание 3. Тестирование форм регистрации и входа

Скрипт `check_forms.py` отправляет в формы 45 наборов данных и сравнивает код ответа и страницу с ожидаемым. Ожидания взяла из требований к порталу (практика 1: логин 3-20 символов из латиницы, цифр и `_`, уникальный; пароль от 8 символов; почта и телефон по формату), а не из того, как портал себя ведёт. Запуск: `python check_forms.py` при запущенном портале (адрес в `PORTAL_URL`). Скрипт каждый раз создаёт новых пользователей со случайными логинами, поэтому его можно запускать повторно.

Версия до исправлений (коммит `ce58475`): 45 проверок, не прошло 5. После исправлений: 45 из 45. Снимки: `screens/01-до-исправлений-check_forms.png`, `screens/02-после-исправлений-check_forms.png`.
